## 1. Overview

`freyacn` is a shadcn/ui-inspired component library for [Freya](https://github.com/marc2332/freya), targeting **Freya
0.5.0-rc.10**.

It is built around four primitives:

| Primitive       | Purpose                                                                                                                                 |
|-----------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| **`Style`**     | A plain data struct holding every styling field (background, typography, borders, spacing, flex, …). `Style::default()` is empty.       |
| **`StyleExt`**  | A trait with one required method, `get_style()`. Provides ~500 chainable methods: `bg_primary()`, `p_4()`, `text_sm()`, `flex_col()`, … |
| **`Variant`**   | A trait with one method, `resolve() -> Style`. Implemented by `#[variant]` enums; consumed by the component macro.                      |
| **`Component`** | A trait with one method, `render(&self) -> impl IntoElement`. Generated by `#[component]`.                                              |

### Installation

```toml
[dependencies]
freyacn = "0.2.0-alpha.1"
```

```rust
use freyacn::prelude::*;
```

The prelude re-exports:

- All components (`Div`, `Button`, `Label`, `Icon`, `Image`, `Avatar*`, `Alert*`, `Divider`, `Group`, `Accordion*`,
  `Grid*`)
- All macros (`#[component]`, `#[variant]`, `#[struct_fields]`, `#[extensions]`, `cn!`)
- `Style`, `StyleExt`, `Variant`
- `Theme`, `Colors`, and theme hooks
- All of Freya's own prelude (`EventHandler`, `Event`, `LaunchConfig`, `WindowConfig`, `State`, `launch`, …)
- All Freya lucide icons (`info()`, `chevron_down()`, `check()`, `alert_circle()`, …)
- `EventHandlerType`, `EventName`, `FxHashMap`
- Utility helpers (`color_with_alpha`, `blend_colors`, `get_color_from_fill`, `apply_opacity`)

**Freya is a transitive dependency** — you never add it to your `Cargo.toml` and never write `use freya::prelude::*`.

## 2. Quick reference — "I want to…"

| Goal                                | Use                                                                         |
|-------------------------------------|-----------------------------------------------------------------------------|
| Set the app theme                   | `use_init_cn_theme(Theme::dark().neutral())`                                |
| Read a theme token                  | `let s = use_cn_theme(); let bg = s.read().background;`                     |
| Lay out children vertically         | `Div().flex_col().gap(8.0)`                                                 |
| Lay out children horizontally       | `Div().flex_row().items_center()`                                           |
| Center content                      | `Div().flex_row().justify_center().items_center()`                          |
| Give a box padding, radius, surface | `Div().p(16.0).corner_radius(8.0).background(card)`                         |
| Add a border                        | `Div().style("border border-border")` — **always pair width + colour**      |
| A primary action                    | `Button().child(Label().text("Save"))`                                      |
| Text                                | `Label().text("Hello").text_sm()`                                           |
| Icons                               | `Icon().svg(info()).size_4()`                                               |
| Images                              | `Image().src("photo.jpg").alt("…").style("object-cover")`                   |
| Avatars with overlap                | `AvatarGroup().child(Avatar()…).child(Avatar()…)`                           |
| Alerts                              | `Alert().child(AlertTitle().text("…")).child(AlertDescription().text("…"))` |
| Collapsible sections                | `Accordion().item("id", "Title", "Body")`                                   |
| Hover-reactive containers           | Add `hover:*` tokens to a `Div` — it owns hover state automatically         |
| Group hover (any descendant reacts) | Wrap in `Group().child(...)`, use `group-hover:*` on descendants            |
| Conditional class strings           | `cn!("base", if active { "active" } else { "" })`                           |
| Tailwind-style string shorthand     | `Div().style("p-4 bg-card rounded-lg")`                                     |
| Typo-check a style string           | `let (s, unknown) = Style::default().style_debug("p-4 fizzbuzz");`          |

## 3. Style system

### 3.1 `Style` struct

`Style` is a plain data container — no component logic lives on it. Every field is `Option<T>`, `Vec<T>`, or a similar
container, so `Style::default()` is empty.

```rust
use freyacn::prelude::*;

let s = Style::default ()
.background(Color::RED)
.p_4()
.corner_radius(8.0);
```

`Style` fields are public. Components read them directly to build Freya primitives. You'll rarely construct a `Style` by
hand — the `StyleExt` methods exist for that — but you'll often inspect one when writing custom components.

### 3.2 `StyleExt` trait

The main API for styling. Every freyacn component implements this trait — `Div`, `Button`, `Label`, `Style`, and any
component produced by `#[component]` with `ext(style)`.

**Required method:**

```rust
pub trait StyleExt: Sized {
    fn get_style(&mut self) -> &mut Style;
}
```

Implement this for any struct, and all ~500 provided methods become available:

```rust
struct MyWidget {
    style: Style
}

impl StyleExt for MyWidget {
    fn get_style(&mut self) -> &mut Style { &mut self.style }
}

let w = MyWidget { style: Style::default () }
.bg_primary()
.p_4()
.text_white();
```

#### Spacing

### 3.3 Style merging

`Style` has explicit merging primitives used by the component macro to combine variant styles, base styles, and user
overrides.

```rust
impl Style {
    pub fn merge(self, other: Style) -> Style;
    pub fn or(self, defaults: Style) -> Style;
    pub fn merge_from(&mut self, other: Style);
    pub fn or_from(&mut self, defaults: Style);
    pub fn is_empty(&self) -> bool;
    pub fn with_active_states(self, active: StateFlags) -> Style;
}
```

| Method               | Behaviour                                                                                                  |
|----------------------|------------------------------------------------------------------------------------------------------------|
| `merge(self, other)` | `other` wins on every field it set. Stack fields (`shadows`, `font_families`, `text_shadows`) concatenate. |
| `or(self, defaults)` | `self` wins; `defaults` fills gaps only.                                                                   |

**Special cases:**

- **`padding` and `margin`** merge *per side*. A variant that sets only `px_4` doesn't wipe the base's `py_2`.
- **`states`** (state-conditional styles) concatenate.

**Style layering rules** (enforced by `#[component]` when `variants(...)` is declared):

```text
Style::default()
    .style("<base>")             // optional, from variants("…", …)
    .merge(variant.resolve())
    .merge(size.resolve())
    .merge(self.style.clone())   // user overrides win
```

**Consequences:**

- **Overrides persist across variant changes.** Calling `.variant("outline")` recomputes the base; the caller's
  `.bg_green_50()` still wins.
- **Theme changes propagate automatically.** `.resolve()` reads `use_cn_theme()` on every render.
- **Base is least specific; user overrides are most specific.** Matches shadcn's `cn(base, variant, size, user)`
  layering.

### 3.4 Style strings

Every `StyleExt` implementor accepts a Tailwind-style token string:

```rust
Div().style("p-4 bg-card rounded-lg shadow-sm hover:shadow-md")
```

Unknown tokens are silently ignored (matches Tailwind).

#### Token categories

**Layout:** `flex`, `inline-flex`, `flex-row`, `flex-col`, `flex-wrap`, `flex-1`, `grow`, `grow-0`, `shrink`,
`shrink-0`, `shrink-1`, `content-*`, `justify-*`, `items-*`, `self-*`, `gap-*`, `w-*`, `h-*`, `min-w-*`, `min-h-*`,
`max-w-*`, `max-h-*`, `size-*`, `grid`, `grid-cols-1…12`, `col-span-*`, `row-span-*`.

**Color:** `bg-<family>-<shade>`, `text-<family>-<shade>`, `border-<family>-<shade>`, `ring-<family>-<shade>`, every
semantic token (`bg-primary`, `text-muted-foreground`, `border-input`, `ring-ring`, `bg-sidebar-accent`, …). Opacity
modifiers: `bg-primary/50`, `text-red-500/[0.37]`. Arbitrary hex: `bg-[#ff0000]`, `text-[#rgb]`, `border-[#rrggbbaa]`.
`color-mix()` is also supported: `bg-[color-mix(in_oklch,...)]`.

**Typography:** `text-xs`…`text-9xl`, `font-thin`…`font-black`, `italic`, `not-italic`, `underline`, `overline`,
`line-through`, `no-underline`, `uppercase`, `lowercase`, `capitalize`, `normal-case`, `text-left/center/right/justify`,
`leading-*`, `tracking-*`, `truncate`, `text-ellipsis`, `text-clip`, `line-clamp-*`, `whitespace-*`, `break-*`,
`text-[12.8px]`.

**Border, radius, effects:** `border`, `border-0/2/4/8`, `border-t/r/b/l/x/y`, `border-<colour>`,
`border-solid/dashed/dotted/double/none`, `rounded`, `rounded-none/sm/md/lg/xl/2xl/3xl/full`, `rounded-[10px]`,
`shadow-sm/md/lg/xl/2xl/none`, `opacity-*`.

**Ring tokens:** `ring`, `ring-0/1/2/3/4/6/8`, `ring-<colour>`, `ring-offset-*`, `inset-ring`. **These parse but don't
render** — Freya has no ring primitive.

**Position, overflow:** `relative`, `absolute`, `global`, `top-*`, `right-*`, `bottom-*`, `left-*`, `inset-*`,
`inset-x-*`, `inset-y-*`, `z-*`, `overflow-clip`, `overflow-none`, `overflow-scroll`, `overflow-scroll-x`,
`overflow-scroll-xy`, `overflow-x-*`, `overflow-y-*`.

**Transforms:** `rotate-*`, `-rotate-*`, `scale-*`, `-scale-*`, `translate-x-*`, `-translate-x-*`, `translate-y-*`,
`-translate-y-*`, `blur-*`, `origin-*`.

**Object fit:** `object-fill`, `object-cover`, `object-contain`, `object-none`, `object-scale-down`.

**Animations:** `animate-spin`, `animate-ping`, `animate-pulse`, `animate-bounce`, `animate-none`, `transition-*`.

#### Negative forms

`-m-4`, `-mt-2`, `-space-x-2`, `-translate-y-1`, `-top-4`, `-rotate-45`, `-scale-90`, `-inset-x-2`. Every negative token
resolves to a negative length before hitting the corresponding positive helper.

#### State prefixes

Chainable: `dark:hover:bg-slate-800`, `focus-visible:ring-2`, `disabled:opacity-50`, `active:bg-muted/80`.

Recognised prefixes: `dark`, `hover`, `focus`, `focus-visible`, `focus-within`, `active`, `disabled`, `visited`,
`checked`, `target`, `first`, `last`, `odd`, `even`, `only`, `group-hover`, `group-focus`, `group-active`, `has-hover`,
`has-focus`, `has-active`, `not-<state>` (e.g. `not-hover:opacity-100`).

**Fold rules:** State tokens parse into `Style::states` as `(StateCondition, Style)` pairs. `Div` computes the active
`StateFlags` at render time and calls `with_active_states()` — one-way fold, later matching entries win.

#### Arbitrary values

Every length token accepts `[<value>]` brackets. Units understood: `px`, `rem`, `em`, `pt`, `%`, `vw`/`vh` (for sizes).

```rust
Div().style("w-[137px] text-[12.8px] gap-[1.5rem] bg-[#ff0000]")
```

#### `style_debug` — typo hunting

```rust
let (style, unknown) = Style::default ().style_debug("p-4 shdaow-md not-a-thing");
assert_eq!(unknown, vec!["shdaow-md", "not-a-thing"]);
```

#### What does NOT work (parses but doesn't render)

| Token                                      | Reason                                         |
|--------------------------------------------|------------------------------------------------|
| `ring-*`, `ring-offset-*`, `inset-ring-*`  | Freya has no ring primitive                    |
| `outline-*`                                | Same — parsed, not rendered                    |
| `overflow-hidden`                          | Not a token — use `overflow-clip`              |
| `grid-cols-[0_1fr]`, variable grid columns | Only equal columns supported                   |
| `has-[>svg]:*`, `[&>svg]:*`                | No descendant selectors                        |
| `sm:`, `md:`, `lg:`                        | No viewport breakpoints — use `use_viewport()` |
| `backdrop-blur` as token                   | Use `.blur(radius)` method or `blur-*`         |

### 4.4 Theme hooks

```rust
// Provide a theme (reuses existing context if present, updates in-place otherwise)

pub fn use_provide_cn_theme(theme: Theme) -> State<Theme>;

// Read the theme with a fallback (never panics)
pub fn get_cn_theme_or_default() -> Readable<Theme>;
```

**Reading theme values — the state-binding rule:**

```rust
// ❌ WRONG: temporary State<Theme> is dropped before `read()` returns
let bg = use_cn_theme().read().background;

// ✅ CORRECT: bind the State to a local first
let state = use_cn_theme();
let bg = state.read().background;
```

`State::read()` returns a guard whose lifetime is tied to `&self`. If the `State` is a temporary, the guard dangles and
you get a compile error (or, with bad luck, a runtime panic).

## 5. Macro system

### 5.1 `#[component]`

Turns a function into a component struct, a PascalCase constructor, and a `foo!(…)` macro.

```rust
#[component(
    props(    prop1: Type1, prop2: Type2 = default_expr, …),
    ext(      extension1, extension2, …),
    variants( [ "base style string", ]
              variant: EnumType = EnumType::Default,
              …),
)]
#[derive(Clone, PartialEq)]
fn MyComponent(required_prop: String) {
    // body
}
```

#### Field sources

| Source                          | Kind      | Field type         | Body sees                   | Setter accepts              |
|---------------------------------|-----------|--------------------|-----------------------------|-----------------------------|
| `fn Foo(name: String)`          | required  | `Option<String>`   | `&String` (panics if unset) | `impl Into<String>`         |
| `props(name: String)`           | optional  | `Option<String>`   | `&Option<String>`           | `impl Into<Option<String>>` |
| `props(name: String = "x")`     | defaulted | `String`           | `&String`                   | `impl Into<String>`         |
| `variants(name: T = default)`   | variant   | `T`                | `&T`                        | `impl Into<T>`              |
| `#[struct_fields(name: T)]`     | internal  | `Option<T>`        | `&Option<T>`                | *(no setter)*               |
| `#[struct_fields(name: T = x)]` | internal  | `T`                | `&T`                        | *(no setter)*               |
| `ext(name, …)`                  | extension | *(trait-specific)* | *(trait-specific)*          | *(no setter)*               |

#### Grammar details

- **No return type needed.** The macro generates the `impl IntoElement` signature.
- **No `.into()` at the end.** The body's last expression is coerced.
- **Groups in any order.** `props` / `ext` / `variants` can appear in any order.
- **Only one base style string per `variants(...)`.** Must come first if present.

#### Generated items

For `fn Button() {}`:

```rust
pub struct ButtonComponent {
    /* props, extensions */
}
impl ButtonComponent { pub fn new() -> Self; /* setters */ }
impl Default for ButtonComponent { /* delegates to new() */ }
impl Component for ButtonComponent { fn render(&self) -> impl IntoElement; }
pub fn Button() -> ButtonComponent { ButtonComponent::new() }

#[macro_export]
macro_rules! Button {
    ($($key:ident = $val:expr),* $(,)?) => {
        ButtonComponent::new()$(.$key($val))*
    };
}
```

Three equivalent ways to construct:

```rust
Button()                                        // function
Button().variant(ButtonVariant::Destructive)    // typed
Button!(variant = "destructive")                // macro
```

#### Compile-time validation

- Duplicate field names across any source → error naming both.
- Field name matching an extension field → error.
- Variant without a default → error.
- `variants(...)` without `ext(style)` → error.
- Base style without `ext(style)` → error.
- Duplicate base style strings → error.

### 5.3 `#[struct_fields]`

Placed **below** `#[component]`. Adds internal storage fields with no setters. Same grammar as `props(...)`.

```rust
#[component(props(subtitle: String))]
#[struct_fields(
    tooltip: MyTooltip,          // Option<MyTooltip>
    hover_count: usize = 0,      // usize
)]
fn Card(name: String) {
    // tooltip: &Option<MyTooltip>, hover_count: &usize
    let _ = tooltip;
    let _ = hover_count;
    Div()
}

// User adds their own trait impls
impl CardComponent {
    fn set_tooltip(&mut self, text: impl Into<String>) {
        self.tooltip.get_or_insert_with(Default::default).text = text.into();
    }
}
```

**Placement is strict** — above `#[component]` produces a targeted compile error.

### 5.4 `#[extensions]` / `ext(...)`

Both forms opt a struct into freyacn's extension bundles.

```rust
// In a #[component]
#[component(ext(style, children, key, event_handlers, accessibility))]
// Standalone
#[extensions(style, children, key)]
#[derive(Clone, PartialEq, Default)]
pub struct PlainBox;
```

**Supported names:**

| Name             | Trait              | Field added                                              | Trait method             |
|------------------|--------------------|----------------------------------------------------------|--------------------------|
| `children`       | `ChildrenExt`      | `children: Vec<Element>`                                 | `get_children`           |
| `key`            | `KeyExt`           | `key: DiffKey`                                           | `write_key`              |
| `style`          | `StyleExt`         | `style: Style`                                           | `get_style`              |
| `event_handlers` | `EventHandlersExt` | `event_handlers: FxHashMap<EventName, EventHandlerType>` | `get_event_handlers`     |
| `accessibility`  | `AccessibilityExt` | `accessibility: AccessibilityData`                       | `get_accessibility_data` |

**Build methods available from these extensions:**

```rust
// ChildrenExt
my_component.child(element)
my_component.children(iter)
my_component.push(element)

// StyleExt
my_component.style("p-4 bg-card")
my_component.bg_card().p_4()

// EventHandlersExt
my_component.on_press( | e| …)
my_component.on_hover( | e| …)

// AccessibilityExt
my_component.a11y_role(AccessibilityRole::Button)
my_component.a11y_alt("…")
my_component.a11y_focusable(true)
```

**`variants(...)` requires `ext(style)`.** The macro builds a merged `style` local in the render body — that's the
`Style` extension's job.

### 6.1 `Div`

The foundational layout primitive. Wraps Freya's `rect()` after folding `Style` into concrete values. **Owns all runtime
state observation** — components that return a `Div` get `hover:` / `focus:` / `active:` / `disabled:` handling for
free.

#### Props

| Prop               | Type                        | Default | Description                                           |
|--------------------|-----------------------------|---------|-------------------------------------------------------|
| `disabled`         | `bool`                      | `false` | Folds `disabled:` state, disables pointer observation |
| `focusable`        | `bool`                      | `false` | Add to tab order                                      |
| `inherit_state`    | `bool`                      | `false` | Inherit parent's active flags                         |
| `custom_a11y_id`   | `Option<AccessibilityId>`   | `None`  | Override a11y id                                      |
| `a11y_role`        | `Option<AccessibilityRole>` | `None`  | ARIA role                                             |
| `a11y_expanded`    | `Option<bool>`              | `None`  | ARIA expanded state                                   |
| `a11y_labelled_by` | `Option<AccessibilityId>`   | `None`  | ARIA labelled-by                                      |
| `a11y_hidden`      | `Option<bool>`              | `None`  | ARIA hidden                                           |

#### Extensions

`style`, `children`, `event_handlers`, `accessibility`, `key`

#### Struct fields

`on_hover: EventHandler<Event<PointerEventData>>`, `on_press: EventHandler<Event<PressEventData>>`

#### Style surface

Full `Style` — background, typography, borders, effects, flex, sizing, spacing, positioning, overflow, animations,
accessibility, and **all state-folded styles**.

#### State observation

`Div` computes active `StateFlags` from:

- `DARK` — from `use_cn_theme()`
- `HOVER` — pointer enters/leaves (via `on_pointer_enter` / `on_pointer_leave`, *not* over/out)
- `ACTIVE` — pointer down
- `FOCUS`, `FOCUS_VISIBLE` — `use_focus(a11y_id)`
- `DISABLED` — `disabled` prop
- `FIRST`/`LAST`/`ODD`/`EVEN`/`ONLY` — from `DivPosition` context (set by parent `Div`)
- `GROUP_HOVER`, `GROUP_FOCUS` — from `Group` ancestor

Publishes this to descendants via `DivActiveState` context.

#### `space_x` / `space_y`

`space-x-*` / `space-y-*` render as **margin-left / margin-top on every child except the first**. Negative values
(`-space-x-2`) produce overlap.

#### `grid_cols` / `col_span`

`Div().style("grid-cols-3")` becomes a grid container. `Div().style("col-span-2")` inside it spans 2 columns.
Implementation uses flex-wrap approximation with context-based sizing — see the `Div` source docs.

#### Example

```rust
Div()
.style("flex flex-col gap-4 p-6 bg-card rounded-lg border border-border")
.focusable(true)
.on_hover( | _ | println!("hovered"))
.on_press( | _ | println!("pressed"))
.child(Label().text("Content"))
```

### 6.2 `Button`

Composite interactive component built on `Div`.

#### Variants

**`ButtonVariant`**: `Default`, `Outline`, `Secondary`, `Ghost`, `Destructive`, `Link`.

**`ButtonSize`**: `Default` (h-8), `Xs` (h-6), `Sm` (h-7), `Lg` (h-9), `Icon` (size-8), `IconXs`, `IconSm`, `IconLg`.

#### Props

| Prop        | Type                                            | Default | Description      |
|-------------|-------------------------------------------------|---------|------------------|
| `disabled`  | `bool`                                          | `false` | Disable button   |
| `focusable` | `bool`                                          | `true`  | Add to tab order |
| `on_hover`  | `Option<EventHandler<Event<PointerEventData>>>` | `None`  | Hover callback   |

#### Extensions

`style`, `children`, `key`, `event_handlers`, `accessibility`

#### Behavior

- Base style + variant + size fold into the effective style.
- Sets `Role::Button` by default.
- Forwards caller's `accessibility`.
- Children (`Label`, `Icon`) are non-interactive by default — the button's `hover:` styles stay applied over its own
  content.

#### Example

```rust
Button()
.variant(ButtonVariant::Destructive)
.size(ButtonSize::Lg)
.child(Label().text("Delete"))
.on_press( | _ | println!("deleted"))
```

### 6.3 `Label`

Text primitive. Renders a `rect()` wrapper around a `label()`, applying text styles to the label and box styles to the
wrapper.

#### Props

| Prop               | Type                        | Default    | Description          |
|--------------------|-----------------------------|------------|----------------------|
| `text`             | `String`                    | `""`       | Text content         |
| `disabled`         | `bool`                      | `false`    | Disabled state       |
| `focusable`        | `bool`                      | `false`    | Add to tab order     |
| `inherit_state`    | `bool`                      | **`true`** | Inherit parent state |
| `custom_a11y_id`   | `Option<AccessibilityId>`   | `None`     | Override id          |
| `a11y_role`        | `Option<AccessibilityRole>` | `None`     | ARIA role            |
| `a11y_labelled_by` | `Option<AccessibilityId>`   | `None`     | ARIA labelled-by     |
| `a11y_hidden`      | `Option<bool>`              | `None`     | ARIA hidden          |

#### Extensions

`style`, `event_handlers`, `accessibility`

#### Style surface

**Text styles** applied to the label: color, font size, weight, slant, width, families, alignment, decoration, height,
shadow, truncation, line-clamp, line-height, letter-spacing, case transform.

**Box styles** applied to the wrapper: sizing, padding, margin, background, border, opacity, transforms, position,
events, a11y.

#### Non-interactive by default

A `Label` inside a `Button` or `AccordionTrigger` reacts to the parent's hover **without stealing it**. Opt in with
`.pointer_events_auto()`:

```rust
Label()
.text("Hover me")
.style("pointer-events-auto hover:underline cursor-pointer")
```

#### Letter-spacing caveat

`Label` **does** forward `Style::letter_spacing` to `label()` — `tracking_tight()`, `tracking_wide()`, etc. work.

#### Example

```rust
Label().text("Hello, world").text_lg().font_semibold()
```

### 6.4 `Icon`

SVG icon component.

#### Props

| Prop  | Type    | Default            | Description |
|-------|---------|--------------------|-------------|
| `svg` | `Bytes` | `Bytes::default()` | SVG data    |

#### Extensions

`style`, `accessibility`, `key`

#### Sizing

- Both `width` and `height` set → uses both
- Only `width` → mirrors to `height`
- Only `height` → mirrors to `width`
- Neither set → **16×16** default

#### Inherits SVG color

The SVG uses `currentColor` — the icon inherits its parent's text color through Freya's cascade.

#### Non-interactive by default

Same as `Label` — inherits hover/focus/active from parent `Div` without stealing it.

#### Example

```rust
Icon().svg(info()).size_4()           // 16×16
Icon().svg(chevron_down()).size_6()   // 24×24
```

Available icon sources from `freyacn::prelude::*` — all Freya lucide icons:

```rust
info(), alert_circle(), check(), chevron_down(), chevron_up(),
chevron_left(), chevron_right(), arrow_right(), plus(), minus(),
x(), search(), menu(), settings(), user(), lock(), mail(), …
```

### 6.5 `Image`

Path-based image primitive mimicking HTML's `<img>`.

#### Props

| Prop           | Type            | Default          | Description                        |
|----------------|-----------------|------------------|------------------------------------|
| `src`          | `String`        | `""`             | File path                          |
| `bytes`        | `Option<Bytes>` | `None`           | Pre-loaded bytes (wins over `src`) |
| `alt`          | `String`        | `""`             | Alt text                           |
| `fit`          | `ImageFit`      | `ImageFit::Fill` | Object-fit mode                    |
| `sampling`     | `SamplingMode`  | `Trilinear`      | Skia sampling                      |
| `snap_to_grid` | `bool`          | `false`          | Pixel-art scaling                  |
| `blur`         | `f32`           | `0.0`            | Blur radius                        |

#### Extensions

`style`, `accessibility`, `event_handlers`, `key`

#### `ImageFit`

```rust
pub enum ImageFit {
    Fill,      // stretch
    Cover,     // crop, centred
    Contain,   // fit inside
    None,      // natural size
}
```

`From<&str>`: accepts `"fill"`, `"cover"`, `"contain"`, `"none"`, `"scale-down"` (maps to `Contain`).

#### Style support

`object-cover`, `object-contain`, `object-fill`, `object-none`, `object-scale-down` tokens — win over the `fit` prop.
`blur-*` tokens — win over the `blur` prop. `rounded-*`, `shadow-*`, `border-*`, sizing, opacity, transforms, position,
z-index — all forward to the underlying element.

#### Supported formats

`skia_safe::Image::from_encoded` supports: PNG, JPEG, WebP, GIF, BMP, ICO, WBMP. AVIF/HEIF/TIFF if the linked Skia has
those codecs. **SVG is not supported** — rasterise first.

#### Caching

File-existence check is cached on `src` via `use_state`. Re-renders don't re-touch the filesystem.

#### Missing files

Missing or corrupt sources render a muted placeholder sized to the caller's constraints.

#### Example

```rust
Image()
.src("assets/photo.jpg")
.alt("Ada")
.style("w-64 h-48 object-cover rounded-lg shadow-md")
```

### 6.6 Avatar family

#### `Avatar`

User/entity avatar. Renders image → fallback child → empty muted box, in that priority.

**Props:**
| Prop | Type | Default |
|---|---|---|
| `src` | `String` | `""` |
| `bytes` | `Option<Bytes>` | `None` |
| `alt` | `String` | `""` |

**Variants:**

- `size: AvatarSize` — `Xs` (24), `Md` (32, default), `Lg` (40), `Xl` (48), `Xxl` (64). Fallback text scales with
  variant.
- `shape: AvatarShape` — `Circle` (`rounded-full`, default), `Rounded` (`rounded-lg`), `Square`.

**Struct fields:**

- `badge: Element` — set via `.badge(...)`

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

**Builder methods:**

- `.fallback(text)` — shortcut for `.child(AvatarFallback().child(Label().text(text)))`
- `.badge(element)` — attach an `AvatarBadge`
- `.bordered()` — add in-group ring on a standalone avatar

**Example:**

```rust
Avatar()
.src("assets/ada.jpg")
.alt("Ada Lovelace")
.fallback("AL")
.size(AvatarSize::Lg)
.badge(AvatarBadge().style("bg-green-500"))
```

#### `AvatarFallback`

A slot for the fallback content — typically initials. Renders a muted centred box that fills the avatar.

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

**Example:**

```rust
Avatar()
.src("photo.jpg")
.child(AvatarFallback().child(Label().text("AL")))
```

#### `AvatarGroup`

A horizontal row of overlapping avatars.

**Props:**
| Prop | Type | Default |
|---|---|---|
| `spacing` | `f32` | `-8.0` |

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

**Behavior:**

- Each child is wrapped in a `Div` with 2px padding filled with `theme.card` — the padded ring is the separator.
- Non-first children get `.ml(spacing)` for overlap and `.z_index(i)` for stacking.

**Example:**

```rust
AvatarGroup()
.child(Avatar().src("a.jpg").alt("A").fallback("A").size(AvatarSize::Lg))
.child(Avatar().src("b.jpg").alt("B").fallback("B").size(AvatarSize::Lg))
.child(AvatarGroupCount().size(AvatarSize::Lg).count(5))
```

#### `AvatarGroupCount`

The "+N more" slot. Styled like an avatar.

**Variants:** `size: AvatarSize`, `shape: AvatarShape`

**Builder method:** `.count(n)` — renders "+n"

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

#### `AvatarBadge`

Corner status dot.

**Variants:** `size: AvatarBadgeSize` — `Sm` (8), `Md` (10, default), `Lg` (12), `Xl` (16)

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

**Positioning:** Absolutely positioned at bottom-right of the avatar's positioning wrapper (added by
`Avatar().badge(...)`). Not clipped by the avatar's `overflow-clip`.

### 6.7 Alert family

#### `Alert`

shadcn-compatible alert container with `role="alert"`.

**Variants:**

- `variant: AlertVariant` — `Default`, `Destructive`

**Struct fields:**

- `icon: Element` — via `.icon(...)`
- `action: Element` — via `.action(...)`

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

**Layout:**

- No icon, no action: `flex_col` with 2px gap.
- With icon and/or action: `flex_row` with columns: icon (shrink-0), content (flex-1), action (absolute top-right).

**Style:**

- `px-4 py-3` → `Gaps::new(12, 16, 12, 16)`
- `rounded-lg` → `theme.radius_lg` (10px, matching shadcn's `--radius`)
- `border border-border`
- `bg-card` from variant

**Example:**

```rust
Alert()
.variant(AlertVariant::Destructive)
.icon(Icon().svg(alert_circle()).size_4())
.child(AlertTitle().text("Error"))
.child(AlertDescription().text("Your session has expired."))
.action(AlertAction().child(Button().child(Label().text("Retry"))))
```

#### `AlertTitle`

Title slot. `font-medium tracking-tight`, one `text-sm` line box tall.

**Props:**
| Prop | Type | Default |
|---|---|---|
| `text` | `String` | `""` |

If `text` is set, renders a `Label` with `.text_sm()` and `.tracking_tight()`. If empty, renders children instead.

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

#### `AlertDescription`

Description slot. `text-sm`, `text-muted-foreground` (or `text-destructive/90` in destructive alerts via
`AlertVariantContext`).

**Props:**
| Prop | Type | Default |
|---|---|---|
| `text` | `String` | `""` |

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

#### `AlertAction`

Action slot. **Absolutely positioned at top-right** of the alert (against the alert's outer box, not the flex row). Pass
via `Alert().action(...)`, not `.child(...)`.

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

**Reserved padding:** Because the action is absolute, long descriptions that share horizontal extent need
`.style("pr-24")` (or similar) on `AlertDescription`. Same requirement as shadcn.

### 6.9 `Group`

Wraps a subtree and exposes its hover/focus state to descendants via `GroupState` context. Enables `group-hover:*` /

**Props:** none

### 6.11 Grid

Grid layout primitives — flex-wrap approximation of CSS Grid.

#### `Grid`

**Props:**
| Prop | Type | Default |
|---|---|---|
| `cols` | `i32` | `2` |

**Extensions:** `style`, `children`, `key`, `event_handlers`, `accessibility`

Publishes `GridColumns` via context. `GridItem` reads it for sizing.

#### `GridItem`

**Props:**
| Prop | Type | Default |
|---|---|---|
| `span` | `i32` | `1` |
| `row_span` | `i32` | `1` |

**Extensions:** `style`, `children`, `key`, `accessibility`

Sizes itself as `(100 / cols) * span %`. `row_span` is stored but not applied (no row-track primitive).

**Caveats:**

- Every child should be a `GridItem`.
- `row_span` doesn't affect layout.
- `gap-*` renders, but per-axis gaps (`gap-x-*` / `gap-y-*`) don't.

**Example:**

```rust
Grid()
.cols(3)
.gap_4()
.child(GridItem().child(Label().text("One")))
.child(GridItem().child(Label().text("Two")))
.child(GridItem().span(2).child(Label().text("Wide")))
```

**Note:** `Div` also supports `grid-cols-*` / `col-span-*` via its own context (`DivGridColsCtx`). Prefer that for new
code — `Grid` / `GridItem` predate it.

## 7. Utilities

### 7.1 `cn!` macro

Concatenates class-name fragments, skipping empties and `None`.

```rust
cn!("px-4", "py-2", "rounded")
// → "px-4 py-2 rounded"

cn!("btn", if active { "btn-active" } else { "" })
// → "btn btn-active" (or "btn" when inactive)

cn!("input", Some("input-lg"), None::<&str>)
// → "input input-lg"

cn!()   // → ""

cn!("a", "b",)   // trailing comma OK → "a b"

// Nesting works
let inner = cn!("text-sm", "font-bold");
cn!("card", inner, "p-4")
// → "card text-sm font-bold p-4"
```

**Accepted argument types** (all implement `CnArg`):

- `&str`, `String`, `Cow<'_, str>`
- `&T`, `&mut T` where `T: CnArg`
- `Option<T>` where `T: CnArg` — `None` is skipped
- `Vec<T>`, `[T]`, `[T; N]` where `T: CnArg`
- A previous `cn!(...)` result

**Custom fragments:** implement `CnArg` for your own types:

```rust
impl CnArg for MyFragment {
    fn write_to(&self, out: &mut String) {
        if !out.is_empty() { out.push(' '); }
        out.push_str(&self.to_string());
    }
}
```

## 9. Patterns and recipes

### 9.1 The interactive-unit pattern

Freya's hit tester routes each pointer event to the **topmost interactive element** under the pointer. When parent and
child are both interactive, moving the pointer onto the child fires `pointer_leave` on the parent — clearing the
parent's hover state.

**The rule:** *The outermost element of a widget is the interactive unit. Its children are non-interactive and react to
the parent's state via `DivActiveState`.*

| Rule                                                                                         | Where                                         |
|----------------------------------------------------------------------------------------------|-----------------------------------------------|
| `Div` is interactive by default, publishes `DivActiveState`                                  | `div.rs`                                      |
| `Label` and `Icon` default to `pointer_events = false`                                       | `label.rs`, `icon.rs`                         |
| `Div`'s `inherit_state` defaults to `false` — a hovered row doesn't light up every child     | `div.rs`                                      |
| `Label`'s `inherit_state` defaults to `true` — a label follows its parent's hover            | `label.rs`                                    |
| Hover/press tracked via `on_pointer_enter` / `on_pointer_leave` (not over/out, which bubble) | `div.rs`, `label.rs`, `group.rs`, `button.rs` |

**Opt in for self-hover on a leaf:**

```rust
Label()
.text("Hover me")
.style("pointer-events-auto hover:underline cursor-pointer")
```

### 9.2 Style layering

```text
Style::default()
    .style(<base>)                // optional, from variants("…")
    .merge(variant.resolve())     // variant, declaration order
    .merge(size.resolve())
    .merge(self.style.clone())    // user overrides — always win
```

**Implications:**

- Variant switches recompute the base — user overrides persist.
- Theme changes propagate automatically (`.resolve()` reads on each render).
- Base is least specific; user overrides are most specific.

### 9.3 Building a component

```rust
use freyacn::prelude::*;

#[variant]
#[derive(Clone, Copy, Debug, PartialEq, Eq, Default)]
pub enum CardVariant {
    #[variant("bg-card text-card-foreground")]
    #[default]
    Default,
    #[variant("bg-destructive/10 text-destructive")]
    Destructive,
}

#[component(
    props(
        title: String,
    ),
    ext(style, children, key, event_handlers, accessibility),
    variants(
        "flex flex-col rounded-lg border border-border p-4 gap-3",
        variant: CardVariant = CardVariant::Default,
    ),
)]
#[derive(Clone, PartialEq)]
pub fn Card() {
    Div()
        .merge_style(style.clone())
        .event_handlers(event_handlers.clone())
        .accessibility(accessibility.clone())
        .child(Label().text(title.as_str()).font_semibold())
        .children(children.clone())
}
```

### 9.4 Custom extension trait

```rust
use freyacn::prelude::*;

pub trait CardExt {
    fn elevated(self) -> Self;
    fn outlined(self) -> Self;
}

impl<T: StyleExt> CardExt for T {
    fn elevated(self) -> Self {
        self.shadow_md().bg_card()
    }
    fn outlined(self) -> Self {
        self.style("border border-border")
    }
}

// Any StyleExt implementor gets the new methods
Div().elevated()
Card().outlined()
```

### 9.5 Responsive behavior

Freya has no breakpoint system. Use `use_viewport()` in Rust code and branch:

```rust
let size = use_viewport();
let is_wide = size.read().width > 768.0;

Div().style( if is_wide { "flex-row" } else { "flex-col" })
```

## 10. Gotchas and pitfalls

### Style parsing

| Symptom                                          | Cause                                           | Fix                                                                                                                   |
|--------------------------------------------------|-------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| `overflow-hidden` does nothing                   | Not a token — parser only knows `overflow-clip` | Use `.style("overflow-clip")` or `.overflow_clip()`                                                                   |
| `border-green-500` alone renders nothing         | Set colour but no width                         | Use `border border-green-500` or `.border_width(2.0).border_color(c)`                                                 |
| `ring-2 ring-primary` parses but no ring appears | Freya has no ring primitive                     | Use `border-*` or `shadow-*` for visible rings                                                                        |
| Negative class `-ml-2` not applied               | Wasn't parsed before `0.2.0-alpha.1`            | Update; current parser handles `-m-*`, `-translate-*`, `-rotate-*`, `-scale-*`, `-inset-*`, `-top-*`, `-left-*`, etc. |
| `grid-cols-3` doesn't render as a grid           | Renders as flex-wrap with equal-width cells     | Use `Div`'s `col_span` for multi-cell items; `Grid` / `GridItem` predate `Div` grid support                           |

### Theming

| Symptom                                  | Cause                                                | Fix                                                                         |
|------------------------------------------|------------------------------------------------------|-----------------------------------------------------------------------------|
| `bg-card` looks transparent              | `card == background` in theme                        | Update to current theme; `card` is now one shade above `background`         |
| `bg-muted` indistinct from `bg-card`     | Wrong hierarchy in old theme                         | Current theme has `background < card < muted`                               |
| `use_cn_theme().read()` fails to compile | `State::read()` guard outlives the temporary `State` | `let state = use_cn_theme(); let v = state.read().X;`                       |
| Theme doesn't update on `.base_color()`  | Chained after `.theme_color()` — base resets accent  | Always chain `.base_color(...)` / `.stone()` **before** `.theme_color(...)` |

### Components

| Symptom                                                   | Cause                                                                         | Fix                                                                                                                    |
|-----------------------------------------------------------|-------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------|
| `text-sm` doesn't affect `Label` inside a component       | Font size doesn't cascade across components                                   | Set `.text_sm()` directly on the `Label` (as `AlertTitle` does)                                                        |
| `flex_shrink: 0` on a child has no effect                 | `Div`'s `flex_shrink` isn't forwarded to `rect()`                             | Not a general concern; `Icon` uses explicit `size_4()` instead                                                         |
| Child renders outside parent when absolutely positioned   | `Div` wraps every child in `WithPosition` — that becomes the containing block | Use `Position::Stacked` wrapper + pass element via a struct field, not `.child(...)` (see `AlertAction` in `alert.rs`) |
| `AlertAction` positioned wrong when passed via `.child()` | Absolute positioning resolves against `WithPosition` wrapper                  | Use `.action(...)`, not `.child(...)`                                                                                  |
| Button shrinks and its label wraps in a flex row          | `flex_shrink` not forwarded to `rect()`; label lacks `whitespace-nowrap`      | Give the button an explicit width or use `Alert`'s `.action(...)` pattern                                              |
| Animation appears to "jump then stick"                    | Front-loaded easing on short durations                                        | Use linear (default) — Freya's `use_animation` linear is fine                                                          |
| `#[struct_fields(...)]` above `#[component(...)]` errors  | Attribute macros processed top-to-bottom                                      | Move `#[struct_fields]` below `#[component]`                                                                           |

### Macros

| Symptom                                           | Cause                                                                      | Fix                                                                           |
|---------------------------------------------------|----------------------------------------------------------------------------|-------------------------------------------------------------------------------|
| `Button().variant("destructive")` doesn't compile | Setter accepts `impl Into<T>` — `&str` → `ButtonVariant` needs `From` impl | `#[variant]` generates the `From` impls automatically; ensure you're using it |
| Required prop panics at render                    | Never set via `.name(...)`                                                 | Either set the prop or make it optional via `props(...)`                      |
| `variants(...)` fails to compile                  | Missing `ext(style)`                                                       | Add `ext(style, children)`                                                    |
| Base style in `variants("…")` fails to compile    | Same as above                                                              | Add `ext(style)`                                                              |
